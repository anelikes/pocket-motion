# Code of Conduct

## The short version

Be decent to people. Argue about the work, not about who is doing it.

## What is expected

- **Disagree about the thing, with evidence.** This project settles arguments
  by measurement wherever a measurement exists. "That is wrong, here is the
  number" is welcome from anyone, about anyone's work, including the
  maintainer's.
- **Assume the other person is trying.** A confusing patch is more often a
  misunderstanding than carelessness.
- **Say when you were wrong**, plainly and without ceremony, and move on.

## What is not

Harassment, personal attacks, demeaning comments about who someone is,
sustained disruption, publishing others' private information, or unwelcome
attention of any kind. This applies in issues, pull requests, commit messages,
and any other space this project occupies.

Rudeness dressed as bluntness is still rudeness. Correctness is not a licence
to be cruel, and a correct review can be delivered without contempt.

## Scope

This applies anywhere someone is representing the project or participating in
its spaces.

## Enforcement

Report to **anelikes@gmail.com**. Reports stay private.

The maintainer will read it and respond. Depending on what happened, the
response ranges from a private word, to editing or removing the content, to
blocking the account. There is no committee and no appeals process — this is a
small project, and pretending otherwise would be theatre.

The maintainer is bound by this document too. If the problem is the
maintainer's behaviour, say so; there is nowhere else to send it, but it will
be read.
